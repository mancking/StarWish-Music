# StarWish Music v1.1 修复清单（v2.0 落地记录）

> 本文档记录 v1.0 预览版暴露的缺陷与新增需求。**v2.0 已按新架构（Electron + Vue3 + TS）全部重做并验证通过**，
> 下表中「状态」列标注落地方式。原 Android / 其他端交付计划已移除，本项目仅提供 Windows 桌面版。

---

## 一、缺陷修复

### 1.1 图标未美化（设置页 / 迷你栏）

- 设置页分类、播放控制、导航全部改为 **24×24 线性 SVG**（`src/components/Icon.vue`），无 emoji 功能图标。
- 播放/暂停/上一首/下一首/循环/随机/收藏/队列/歌词均有独立图标，按钮有明确前景色。
- **状态：✅ 已修复**。

### 1.2 播放页封面未同步

- 切歌时按「歌曲封面 → 音源插件 pic → iTunes 兜底 → 渐变占位」四级回退，统一转 `swcover://` 协议。
- 黑胶中心、迷你栏、模糊背景、队列、列表全部使用同一封面地址。
- 封面加载完成触发主色提取，全站强调色随之变化。
- **状态：✅ 已修复**（实测黑胶封面 600×600 正常显示）。

### 1.3 进度条不能点击调节

- 自研 `Slider` 组件：点击跳转、拖动实时预览、松手 seek、键盘方向键微调。
- 迷你栏与播放页共用，拖动时暂停位置插值，避免回跳。
- **状态：✅ 已修复**。

### 1.4 舞台切换按钮无效

- 歌词 / 粒子 / 电影镜头 / 播客 DJ 四态互斥切换，激活态高亮并持久化。
- 粒子舞台使用 Canvas 绘制（随播放脉冲），电影镜头为缓慢缩放运镜，播客模式降级为波形。
- **状态：✅ 已修复**。

### 1.5 播放页按钮隐形

- 控制栏固定布局：`[模式] [收藏] —— [上一首] [播放] [下一首] —— [音质] [音量] [队列] [更多]`。
- 主播放按钮 62px 白底，其余 46px 透明按钮，图标色随主题。
- **状态：✅ 已修复**。

### 1.6 视频 / MV 页面

- 视频/MV 为独立一级页面，卡片网格。
- 点击进入**内置播放器页**（非弹窗）：16:9 视频 + 右侧分集列表 + 同作者推荐。
- 支持分 P 切换、「听音频」把当前分 P 加入音频队列。
- 未登录视频源时可播放低清晰度；设置页支持扫码登录解锁更高清晰度。
- **状态：✅ 已修复并增强（新增分集模式）**。

### 1.7 其他已修复问题

| 问题 | 修复 |
|---|---|
| 点击播放/收藏静默失败 | IPC 出站参数统一 `toPlain()`，解决 Vue Proxy 无法结构化克隆 |
| 封面大量 403 | 主进程代理 + Referer + 磁盘缓存 |
| 网易云外链跳转 http 被拦截 | 媒体代理优先 Node 原生 fetch，回退 net.fetch |
| 首页长时间空白 | 聚合请求并行 + 30 分钟落盘缓存 + 分区骨架屏 |
| 搜索 10 秒以上 | 原生接口并行 + 插件 2.6s 截止 + 相关度排序（实测 <1.5s） |
| 歌词经常为空 | 插件 → 平台官方 → 同名+时长匹配，多候选取优（实测 63 行） |
| 榜单点击报「歌单不存在」 | 三接口回退 + 按域名限流 |
| 主界面两个设置入口 | 移除顶栏设置图标，仅保留侧栏入口 |
| 内置音源不可管理 | 内置音源可移除/恢复，与用户音源一致 |

## 二、功能需求（全部保留）

### 2.1 内置音源

- 随包提供 lx-music 协议音源，首次启动自动注册。
- 视频音源（需登录）与音频音源并列，可独立启停。
- 设置页可查看任意音源源码，作为开发范本；详见 `docs/音源开发指南.md`。

### 2.2 主界面歌单区 + 排行榜区

- 推荐歌单：标签筛选、3–6 列网格、真实封面、作者/播放量。
- 排行榜：按音源分组、左侧榜单树、右侧歌曲表（# / 歌曲 / 艺术家 / 专辑 / 时长）。
- 平台歌单导入：粘贴链接自动识别，保存为本地歌单。

### 2.3 视觉主题

- 深色默认、浅色/跟随系统可切换。
- 强调色默认跟随封面主色，也可自定义。
- 玻璃拟态、柔和渐变、统一圆角与阴影。

### 2.4 播放与歌词

- 音质降级、自动换源、失败跳过、淡入淡出、倍速、定时关闭。
- 歌词：逐字、翻译、偏移校准、点击跳转、桌面歌词（锁定穿透）。

### 2.5 本地音乐

- 文件夹扫描、标签解析、内嵌封面、内嵌歌词、同名 `.lrc`。
- 曲库筛选与播放。

```powershell
cd app
npm install
npm run build
npm run dist:portable
```

不再交付：start.bat、网页版预览、Android APK、其他端产物。
