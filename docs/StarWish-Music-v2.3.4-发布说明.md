  操作按钮行），**描述与按钮不再重叠**；重命名/删除改为右上角圆形图标钮；

### 视频 MV
- **封面修复**：真机所有封面统一走 `/swmedia/` 原生代理——B 站等图片 CDN
  有 Referer 防盗链，此前 WebView 直连带 localhost Referer 被 403 拒图
- **播放器重做（模板级）**：移动端独立控制条——两行布局（播控+时间+画质/倍速/
  画中画/全屏 一行，连播/循环/画面/声音 chips 横滑一行），去掉桌面音量滑杆
  （用系统音量）；桌面控制条原样保留
- **加载更多修复**：触底自动加载改用 IntersectionObserver（此前版本哨兵元素
  未接线，触底加载失效）

### 我的
- 删除重复模块：「视频内容」「应用」两区移除（视频在底栏、设置在资料卡右上角），
  保留资料卡 / 四宫格快捷 / 我的歌单三个模块

### 设置
- **模板级重做移动端**：由「桌面侧栏分类 + 单面板」改为**单页滚动全分区**

### 视频播放器（追加）
- **控制条收纳**：连播 / 循环 / 画面模式 / 弹幕开关 / 静音 全部收进「更多」菜单，
  控制条只留播控、时间、画质、倍速、画中画、全屏
- **离线缓存去重**：移除控制条内重复的缓存入口，仅保留信息区一处
- **新增离线缓存管理器**：全量列表 / 占用统计 / 单条删除 / 一键清空——
  桌面端入口在「我的音乐 → 本地音乐」下方，移动端在「我的」宫格
- **新增播放进度记忆**：按 bvid+分P 记录播放位置（每 3 秒落盘），
  再次打开自动恢复并提示「已恢复到上次播放进度」

## 第二轮：桌面端根因修复（反馈驱动）

> 本轮针对桌面端 4 个反馈项，均为**根因型缺陷**，以重构而非打补丁方式修复。

### 私人电台（多端）—— 不再显示历史歌 / 榜单内容
- **根因**：旧实现「私人电台」区块直接渲染播放次数最多的历史歌曲（onRepeat），
  降级路径又取榜单，因此内容必然是历史歌或榜单，没有任何电台逻辑。
- **修复**：新建 `electron/core/radio.ts` 电台引擎——收藏×3 + 历史 + 播放次数建立歌手
  口味画像 → 取 Top 歌手用搜索扩展同歌手其它作品（主力）→ 新歌底料 → 榜单兜底 →
  剔除近 200 首已听（收藏保留）→ 跨区块去重（与每日推荐/新歌/榜单互斥）→ 按歌手交错编排。
- **实测**：60 首零重复；与历史/收藏/每日推荐/新歌/榜单交集**全为 0**；样本均为新歌。

### 桌面 MV 播放器 —— 找回丢失的全部控制功能
- **根因**：控制条模板桌面分支**根本没有 DOM**（仅有移动端分支），所以只剩裸视频。
- **修复**：补齐桌面控制条——播放/暂停、±5 秒、时间、**音量滑杆 + 静音**、画质菜单、
  倍速菜单、更多菜单（循环/画面比例/自动连播/弹幕）、**画中画**、**全屏**。
- **实测**：9 个按钮 + 3 个菜单全部渲染，画质选项 `["64P","16P"]` 可展开。

### 播放器舞台切换 —— 消除「延迟 + 变化小」
- **根因**：歌词/粒子/电影/DJ 四个舞台类**全项目无任何 CSS**，切换时 DOM 与尺寸不变。
- **修复**：四态差异化布局（封面列宽 340→280→320→210px、栅格列宽随舞台变化、
  粒子加强光晕、DJ 收窄封面）；右侧内容 `stage-fade` 过渡；网格/宽度/opacity 加 .32s 过渡。
  移动端同步：封面/歌词方向感知过渡 + 新增粒子/DJ 舞台（呼吸光晕 + 28 根律动波形）。

### 启动耗时 —— 10 秒 → 0.6 秒
- **根因**：`initDb()` + `lxHost.load()` 在主线程串行执行，窗口在其后才创建 → 长时间空窗。
- **修复**：窗口先行（先 registerIpc → createMainWindow）→ IPC 启动就绪闸门（20s 超时兜底）→
  渲染层先挂载后取数（player/library 后台并行，不再阻塞首屏）。
- **实测**：空库 553ms 可见 / 600ms 首帧；真实数据（47MB + 385KB DB）566ms / 605ms。

### 桌面端应用内更新（补齐）
- 新建 `electron/core/updater.ts`：重定向跟随的流式下载（带进度）+ 重启替换
  （spawn 分离进程 + app.relaunch）。设置页「前往下载」升级为「下载并安装」，
  并支持「重启并安装」「打开所在文件夹」。

### 数据层跨区块去重加强
- `recommend.ts` 每日推荐 / 新歌 / 榜单三方互斥（两两交集为 0，内部无重复）；
  新歌取数池 10 → 36（去重后仍剩 26 首，避免区块被吃空）。
