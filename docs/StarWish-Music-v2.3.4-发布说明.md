# 星河音乐 v2.3.4 发布说明

> 发布日期：2026-10-22 ｜ 代号：真机三轮反馈收口
> 上一版本：2.3.3（2026-10-22）

## 移动端修复与重构（真机三轮反馈）

### 推荐页（首页）
- **新增搜索框**：问候语下方大号搜索框，输入即达搜索页
- **去除重复入口**：快捷胶囊只保留「每日推荐 / 排行榜」两个有实际动作的项，
  移除与底栏 tab 重复的「我喜欢的 / 发现音乐 / 视频 MV」

### 歌单详情
- 模板级重做移动端头部：上下两段布局（封面 + 标题信息 / 描述独占整行 /
  操作按钮行），**描述与按钮不再重叠**；重命名/删除改为右上角圆形图标钮；
  全部按钮 46px 触控目标

### 发现页
- 「排行」更名「**排行榜**」
- 榜单条目点击改为**打开榜单详情页**（完整曲目 + 整体播放），不再无反馈直达
- 小蜗音乐（酷我）等各源榜单统一走详情页，加载/播放错误可视化

### 视频 MV
- **封面修复**：真机所有封面统一走 `/swmedia/` 原生代理——B 站等图片 CDN
  有 Referer 防盗链，此前 WebView 直连带 localhost Referer 被 403 拒图
- **播放器重做（模板级）**：移动端独立控制条——两行布局（播控+时间+画质/倍速/
  画中画/全屏 一行，连播/循环/画面/声音 chips 横滑一行），去掉桌面音量滑杆
  （用系统音量）；桌面控制条原样保留
- **加载更多修复**：触底自动加载改用 IntersectionObserver（此前版本哨兵元素
  未接线，触底加载失效）

### 我的
- 删除重复模块：「视频内容」「应用」两区移除（视频在底栏、设置在资料卡右上角），
  保留资料卡 / 四宫格快捷 / 我的歌单三个模块

### 设置
- **模板级重做移动端**：由「桌面侧栏分类 + 单面板」改为**单页滚动全分区**
  （分区标题吸顶分隔、强调色标注），不再复用桌面表单布局

### 视频播放器（追加）
- **控制条收纳**：连播 / 循环 / 画面模式 / 弹幕开关 / 静音 全部收进「更多」菜单，
  控制条只留播控、时间、画质、倍速、画中画、全屏
- **离线缓存去重**：移除控制条内重复的缓存入口，仅保留信息区一处
- **新增离线缓存管理器**：全量列表 / 占用统计 / 单条删除 / 一键清空——
  桌面端入口在「我的音乐 → 本地音乐」下方，移动端在「我的」宫格
- **新增播放进度记忆**：按 bvid+分P 记录播放位置（每 3 秒落盘），
  再次打开自动恢复并提示「已恢复到上次播放进度」

## 多端产物完整性（延续 v2.3.3 加固）

- Android APK：入口页 / 配置 / cordova.js / sql-wasm / 39 个 js+css+wasm
  逐文件对账通过；SwBridgePlugin 已编入 dex
- Windows 便携版：asar 内 renderer 入口与 chunk、音源脚本 11 个逐项核验通过
- CI 断言扩充：cordova.js / sql-wasm.wasm / 产物数量对账
