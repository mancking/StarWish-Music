# 星河音乐 · 音源开发指南

本指南面向想为星河音乐编写音源脚本的开发者。星河音乐不内置任何平台接口，**所有在线数据都来自你导入的音源脚本**；脚本运行在独立沙箱中，只能通过宿主提供的 API 发起网络请求。

---

## 1. 运行环境与安全边界

| 能力 | 是否可用 | 说明 |
|---|---|---|
| `lx.request` | ✅ | 唯一网络出口，宿主统一处理超时/重试/限流 |
| `lx.utils` | ✅ | md5 / AES / RSA / Buffer / zlib |
| `console` | ❌ | 已静音，调试请用返回值或宿主日志 |
| `require` / `import` | ❌ | 沙箱无模块系统 |
| DOM / `window` / `document` | ❌ | 纯 JS 逻辑环境 |
| 文件系统 | ❌ | 不允许读写本地文件 |
| 定时器 | ✅ | `setTimeout` / `setInterval` 可用 |

- 单个脚本加载超时 20 秒；请求默认 15 秒超时。
- 脚本抛错只会让该音源标记为「加载失败」，不影响其他音源。
- 音源在设置页可随时停用、移除、恢复，用户完全自主管理。

---

## 2. 脚本基本结构

一个音源脚本就是一个 JS 文件，通过 `lx.on` 注册回调、`lx.send` 上报初始化信息。

```js
/*!
 * @name 示例音源
 * @version 1.0.0
 * @author your-name
 * @description 仅用于演示 lx-music v2 协议
 */

const { EVENT_NAMES, request, on, send, utils, env, version } = lx

// 1) 初始化：告诉宿主你支持哪些平台、哪些动作、哪些音质
on(EVENT_NAMES.inited, info => {
  send(EVENT_NAMES.inited, {
    status: true,
    name: '示例音源',
    version: '1.0.0',
    author: 'your-name',
    description: '演示音源',
    sources: {
      demo: {
        name: '示例平台',
        type: 'music',
        actions: ['musicSearch', 'musicUrl', 'lyric', 'pic'],
        qualitys: ['128k', '320k'],
      },
    },
  })
})

// 2) 请求处理：所有动作都从这里进入
on(EVENT_NAMES.request, async ({ source, action, info }) => {
  switch (action) {
    case 'musicSearch':
      return search(info.musicInfo.keyword)
    case 'musicUrl':
      return getUrl(info.musicInfo, info.type)
    case 'lyric':
      return getLyric(info.musicInfo)
    case 'pic':
      return getPic(info.musicInfo)
    default:
      throw new Error('不支持的动作：' + action)
  }
})
```

> 说明：`lx` 是宿主注入的全局对象，等价于 `globalThis.lx`；`request/on/send/utils/EVENT_NAMES` 也已挂到全局，可直接使用。

## 3. 初始化信息（inited）

```js
send(EVENT_NAMES.inited, {
  status: true,
  name: '音源名称',
  version: '1.0.0',
  author: '作者',
  description: '简介',
  sources: {
    // key 是平台标识，会出现在请求的 source 字段
    wy: {
      name: '平台显示名',
      type: 'music',
      actions: ['musicSearch', 'musicUrl', 'lyric', 'pic'],
      qualitys: ['128k', '320k', 'flac'],
    },
  },
})
```

| 字段 | 说明 |
|---|---|
| `actions` | 支持的动作：`musicSearch` / `musicUrl` / `lyric` / `pic` |
| `qualitys` | 支持的音质：`128k` / `320k` / `flac` / `flac24bit` |

宿主会按 `qualitys` 与实际请求音质做降级（24bit → flac → 320k → 128k）。

## 4. 动作详解

### 4.1 搜索 `musicSearch`

入参：

```js
{
  source: 'demo',
  action: 'musicSearch',
  info: {
    musicInfo: { keyword: '晴天', searchTerm: '晴天' },
    keyword: '晴天',
    page: 1,
    pagesize: 30,
  },
}
```

返回数组，每项字段：

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | ✅ | 歌曲名 |
| `singer` | ✅ | 歌手，多个用 `/` 分隔 |
| `songId` | ✅ | 平台内唯一 ID（用于取链/歌词） |
| `albumName` | | 专辑名 |
| `duration` | | 时长（秒） |
| `pic` | | 封面 URL（http/https） |
| `qualitys` | | 该歌曲支持的音质 |
| 其他 | | 平台原始字段（songmid / hash / cid…），会原样回传给 `musicUrl` |

### 4.2 取链 `musicUrl`

入参 `info.musicInfo` 是搜索返回的完整对象（含自定义字段），`info.type` 是请求音质。

返回**字符串 URL**（http/https）。宿主会用 `swmedia://` 代理播放，自动注入 Referer。

```js
async function getUrl(musicInfo, quality) {
  const res = await request(`https://api.example.com/url?id=${musicInfo.songId}&q=${quality}`, {
    method: 'GET',
    headers: { Referer: 'https://example.com/' },
  })
  if (res.statusCode !== 200) throw new Error('取链失败：HTTP ' + res.statusCode)
  const url = res.body?.data?.url
  if (!url) throw new Error('该歌曲无可用地址')
  return url
}
```

### 4.3 歌词 `lyric`

返回字符串（LRC / QRC / YRC 均可），或对象 `{ lyric, tlyric }`。

```js
return '[00:00.00]歌名\n[00:02.00]第一句歌词\n'
```

宿主支持：多时间标签、翻译行配对、逐字标签 `<00:02.10>`。

### 4.4 封面 `pic`

返回封面 URL 字符串，或 `{ url }`。宿主会走 `swcover://` 代理并缓存。

## 5. 网络请求 `lx.request`

```js
const res = await request(url, {
  method: 'GET',                 // GET / POST
  headers: { Referer: '...' },   // 自定义请求头
  body: { a: 1 },                // 对象自动 JSON；字符串原样发送
  timeout: 15000,                // 毫秒
})
```

返回：

```js
{
  statusCode: 200,
  statusMessage: 'OK',
  headers: { 'content-type': 'application/json' },
  body: { ... },   // 自动 JSON 解析；非 JSON 为字符串
  raw: '...',      // 原始文本
  bytes: 1234,
}
```

也支持回调写法（兼容旧脚本）：

```js
request(url, { method: 'GET' }, (err, resp, body) => {
  if (err) return
  // body 已解析
})
```

> 注意：宿主对同一域名有并发限制（默认 3），请避免一次性发起大量请求。

## 7. 完整可运行示例

下面这个音源使用公开的 iTunes Search API，**无需任何密钥**，可直接导入验证协议链路：

```js
/*!
 * @name iTunes 示例音源
 * @version 1.0.0
 * @author starwish
 * @description 演示 search / url / pic 三个动作
 */

const { EVENT_NAMES, request, on, send } = lx

on(EVENT_NAMES.inited, () => {
  send(EVENT_NAMES.inited, {
    status: true,
    name: 'iTunes 示例音源',
    version: '1.0.0',
    author: 'starwish',
    description: '公开 API 演示',
    sources: {
      itunes: {
        name: '示例曲库',
        type: 'music',
        actions: ['musicSearch', 'musicUrl', 'pic'],
        qualitys: ['128k'],
      },
    },
  })
})

on(EVENT_NAMES.request, async ({ action, info }) => {
  if (action === 'musicSearch') {
    const kw = info.musicInfo.keyword
    const res = await request(
      `https://itunes.apple.com/search?term=${encodeURIComponent(kw)}&entity=song&limit=20`,
      { timeout: 12000 }
    )
    return (res.body.results || []).map(item => ({
      name: item.trackName,
      singer: item.artistName,
      songId: String(item.trackId),
      albumName: item.collectionName,
      duration: Math.round(item.trackTimeMillis / 1000),
      pic: (item.artworkUrl100 || '').replace('100x100', '600x600'),
      _url: item.previewUrl, // 自定义字段：取链时直接使用
      qualitys: ['128k'],
    }))
  }

  if (action === 'musicUrl') {
    if (!info.musicInfo._url) throw new Error('无试听地址')
    return info.musicInfo._url
  }

  if (action === 'pic') {
    return info.musicInfo.pic
  }

  throw new Error('不支持的动作：' + action)
})
```

把以上内容保存为 `itunes-demo.js`，在「设置 → 音源与插件 → 导入音源」选择本地文件即可。

## 8. 导入与调试

1. **导入**：设置 → 音源与插件 → 导入音源 → 粘贴 URL 或选择本地 `.js`。
2. **启停**：列表右侧开关。
3. **查看源码**：点击铅笔图标，可直接参考内置音源实现。
4. **移除 / 恢复**：内置与导入音源都可移除；「恢复内置音源」一键还原。
5. **日志**：`%APPDATA%\StarWish\logs\starwish-YYYY-MM-DD.log`，搜索 `lx-host` 查看加载错误。
6. **常见错误**：

| 提示 | 原因 |
|---|---|
| `不是有效的 lx-music 音源脚本` | 缺少 `lx.request` / `EVENT_NAMES` 等特征 |
| `脚本加载失败：xxx` | 语法错误或顶层抛异常 |
| `平台 xx 没有可用的取链音源` | 该平台未声明 `musicUrl` 动作 |
| `取链超时` | 接口 15 秒未返回，检查网络或接口可用性 |

## 9. 开发建议

- **不要硬编码密钥**：公开仓库中的脚本会被所有人看到。
- **做好降级**：`musicUrl` 失败时抛出明确错误，宿主会自动换源。
- **控制并发**：搜索接口一次只发一个请求；批量取链交给宿主调度。
- **字段完整**：`duration`、`albumName`、`pic` 越完整，界面体验越好。
- **遵守版权**：音源仅供个人学习与试听，请勿用于商业分发。

---

## 10. 发布与分享

- 脚本单文件即可分发，建议在文件头写清 `@name/@version/@author/@description`。
- 不要把受版权保护的音频文件打包进脚本。
- 音源失效属于常态，欢迎在仓库 Issue 中反馈，但请勿提交侵权内容。
