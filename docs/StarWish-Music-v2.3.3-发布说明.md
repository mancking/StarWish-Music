# 星河音乐 v2.3.3 发布说明

> 发布日期：2026-10-22 ｜ 代号：启动白页热修复
> 上一版本：2.3.2（2026-10-22）

## 紧急修复

### 启动显示「网页无法打开」（Android）

- **现象**：安装 2.3.2 后启动应用，WebView 直接显示系统错误页「网页无法打开」。
- **根因**：打包机上的 `cap sync` 在删除旧 web 资源后中断（文件系统错误），
  **APK 里缺失入口页 `assets/public/index.html` 与运行配置**——主框架加载 404，
  WebView 只能展示错误页。应用代码本身没有问题。
- **修复**：
  1. 重新完整同步并逐文件校验，重建 APK；已在成品 APK 内断言
     `assets/public/index.html` 与 `capacitor.config.json` 存在（解包核验通过）。
  2. **CI 加固**：`build-mobile.yml` 在 sync 后与打包后各加一道产物完整性断言；
     `build-desktop.yml` / `release.yml` 对桌面渲染层入口同样加断言——
     今后任何一端「能打包但缺入口」都会直接构建失败，不会再流到用户手上。

其余内容与 2.3.2 完全一致（底栏四页模板级重写、返回手势根因修复、
显示截断修复、歌单切换反馈修复），未新增任何功能改动。

## 升级说明

- 2.3.2 用户直接覆盖安装（versionCode 2003003 > 2003002，可正常升级）。
- 若 2.3.2 曾出现「网页无法打开」，升级本版即可恢复正常。
