# 星河音乐 v2.3.2 发布说明

> 发布日期：2026-10-22 ｜ 代号：移动端模板级重构
> 上一版本：2.3.1（2026-10-22）

## 本次重点

针对 2.3.1 真机二轮测试反馈，完成**模板级**重构（不再有桌面模板缩放/样式补丁），
并修复返回手势导致应用直接退出的问题。

### 1. 返回手势不再退出应用（根因修复）

- **根因**：Capacitor 6 的 BridgeActivity 未接管 `onBackPressed`，系统返回
  （含手势）在 WebView 历史尽头时直接退出应用。
- **修复**：`MainActivity.onBackPressed` 统一转成前端 `backButton` 事件，
  新增统一返回处理器 `src/mobile/back-handler.ts`：
  1. 播放队列/弹层打开 → 先关弹层
  2. 路由栈可回退 → 正常回退（边缘右滑手势同路）
  3. 已在根路由 → **双击确认，退到后台不杀进程**（保留后台播放）

### 2. 移动端首页：全新模板

`pages/mobile/Home.vue` 独立实现（与桌面模板零共享 UI）：
- 问候头三行短文案（日期 / 问候语 / 副标题），彻底解决「介绍语显示不全」
- 快捷入口横滑胶囊（每日推荐 / 我喜欢的 / 排行榜 / 发现 / 视频）
- 继续收听、推荐歌单、单曲循环 → 横滑大卡（scroll-snap）
- 新歌速递 → 编号列表（前三名强调色）
- 音乐回忆 / 按心情听 → chips
- 所有文案单行完整省略，不再有截断

### 3. 移动端发现页：全新模板

`pages/mobile/Discover.vue` 独立实现：
- 分段式 tab 吸顶（歌单 / 排行 / 新歌）
- 音源与分类全部横滑胶囊、最热/最新分段切换
- 歌单 2 列大封面卡；榜单纵向排名卡（点整行即播）；新歌编号列表

### 4. 歌单切换反馈修复

桌面/移动共用的发现页逻辑：SWR 缓存命中后原先有 30s 防抖会**吞掉后台刷新**，
导致切回旧分类永远看到旧数据。现在**用户切换必触发后台刷新**，缓存保证秒开、
数据保证更新。

### 5. 显示不全修复（组件级）

- 歌单/列表歌曲行：桌面 5 列网格改为移动 3 列（序号 / 歌名满宽 / 操作），
  隐藏列不再占轨道——歌单中歌曲名显示不全修复
- MV 播放页：桌面「视频 + 300px 侧栏」双栏 → 移动单栏满宽——视频显示不全修复
