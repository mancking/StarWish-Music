覆盖端：Android 手机 / Android 平板 / 车机（Android Automotive）/ Windows / Linux / macOS / iOS 手机 / iOS 平板。
本版本要求：所有列出功能一次性全部做完，不分优先级、不砍不减。无广告，任何位置不插入广告。配色允许按需扩展同色系辅助色。
本文档是唯一执行依据。开发时严格按文档实现，不允许自行增减功能、不允许调整像素参数。文档未覆盖的边界情况，停下来问，不要自己决定。
0.1

多端断点矩阵

同一套代码，按宽度和设备类型自动切换布局。车机单独走车机专用布局，不按宽度判断。
设备分类 手机 Phone 竖屏宽度 < 600px
平板 Tablet 600px ~ 1024px（横/竖屏自适应）
桌面 Desktop ≥ 1024px（Windows / Linux / macOS 窗口化）
车机 Car 通过 UA 或配置项识别为车机，强制走车机布局（横屏、大字、少交互）
布局切换规则 ① 先判断是否车机 → 是则走车机布局，无视宽度。
② 否则按 CSS 宽度断点：<600 手机 / 600~1024 平板 / ≥1024 桌面。
③ 平板横屏（≥900 宽）走接近桌面的两栏布局；竖屏（<900）走手机布局。
禁止不允许新增其他断点。不允许按操作系统（Win/Mac/Linux）做差异化 UI——三个桌面端 UI 完全一致，仅打包脚本不同。

0.3

性能分级降级规则

判定条件满足任一即视为"低性能设备"：① hardwareConcurrency < 4；② 手机/平板/车机 UA；③ 用户在设置中手动开启省电模式。
降级动作 ① 粒子数量：桌面 200 → 手机/平板 50 → 车机 0（不显示粒子）；
② 封面模糊：桌面 blur(30px) → 手机/平板 blur(12px) → 车机不模糊；
③ 舞台频谱：桌面全屏 64 柱 → 平板 32 柱 → 手机 16 柱窄条 → 车机不显示；
④ 唱片旋转：桌面/平板旋转 → 手机静态封面 → 车机静态封面。
车机特殊规则车机端强制关闭所有动效（粒子、频谱、模糊、旋转），只保留静态封面和歌词。驾驶安全优先。
0.4

功能分级（哪些必做、哪些不做）

CORE 全部必做 本规格书列出的所有功能一次性全部做完，不分优先级、不分版本。包括：
音乐播放：播放/暂停/切歌/进度/循环/封面唱片（全端统一圆形旋转）/歌词/粒子/舞台频谱/桌面歌词悬浮窗/快捷键/手势/EQ 均衡器（6预设+5段滑块）/下载（多线程+断点续传）/本地文件扫描/播放缓存（50首/500MB）。
视频播放：循环（含AB段）/画面适应/画质档位/全屏/倍速/手势/画中画/记忆位置/字幕音轨切换/视频转音频模式（含音频提取保存MP3、视频仅音频下载）。
页面：推荐首页（时间+问候语+搜索框+星河Logo底部卡片）/我喜欢的音乐/最近播放/本地音乐/下载管理。
CAR 车机专用 仅车机端启用：大字模式（文字最小 20px、按钮最小 56px）、简化控制栏（只保留播放/暂停/上下首/全屏）、琥珀黄强调色、驾驶勿扰模式（控件持续显示不自动隐藏）。
车机端不做：粒子、频谱、模糊背景、手势、快捷键、下载、本地扫描、画中画。
不做 本版本仅明确不做：① 任何形式广告（开屏/横幅/信息流/推广）；② 需要自建服务器的功能（登录注册、社交评论关注、云端同步、用户系统）。
除此之外，规格书内列出的所有功能全部实现，不设其他限制。皮肤商店、主题自定义后续版本可加。
无广告承诺：本应用任何位置不插入广告、不显示推广 banner、不做开屏广告、不做信息流广告。这是硬约束，永久有效。

0.6

代码架构要求：模块化重构

硬性要求：必须按模块化结构开发，禁止在旧代码上打补丁修补。如果现有代码结构混乱，必须先重构再开发新功能。
模块拆分 ① player-core/：播放内核（AudioContext、播放状态机、进度调度），音乐和视频共用；
② player-music/：音乐播放器 UI（唱片、歌词、粒子、频谱、EQ）；
③ player-video/：视频播放器 UI（画面、控制栏、适应、画质、画中画）；
④ pages/：推荐首页、我喜欢的音乐、最近播放、本地音乐、下载管理；
⑤ platform/：端侧适配（手机手势、桌面快捷键、车机布局、原生存储权限）；
⑥ storage/：本地数据库、下载管理、缓存管理。
模块边界音乐播放器和视频播放器 UI 完全隔离，不互相 import 业务组件。共用逻辑只放在 player-core 和 storage 里。
禁止补丁式开发 ① 不允许在已有函数里加 if-else 硬塞新逻辑；
② 不允许复制粘贴代码改改变量名；
③ 不允许在全局事件监听里塞业务逻辑；
④ 新功能必须新建独立模块/组件，通过接口调用。
状态管理全局播放状态用单一 store（当前歌曲/视频、播放状态、进度、音量、循环模式）。各模块订阅 store，不直接互相操作 DOM。

1.0

音乐播放器模块

MUSIC
原有功能全部保留：封面、歌词、粒子、舞台、循环。按四端形态分别规定尺寸和交互。
1.1 播放页布局（四端分别规定）
手机 单列垂直布局。顶部导航栏高 48px（左返回、中标题、右更多）。下方居中圆形唱片 200×200px，边框 6px 黑。唱片中心 60px 封面图。唱片下歌名 16px + 歌手 12px。进度条。控制按钮组（上一首/播放/下一首）。左右 padding 20px。
平板 横屏：两栏 Grid，左栏 320px 放唱片+控制，右栏 1fr 放歌词。竖屏：走手机单列布局。
桌面 两栏 Grid：左栏 1fr 垂直居中（唱片 200px + 歌名 + 进度条 + 控制按钮），右栏固定 280px 歌词面板。右栏可隐藏，隐藏后左栏占满。
车机 横屏单栏。左侧 1/3 显示歌曲信息（歌名 28px、歌手 18px），右侧 2/3 显示三个大控制按钮（上一首/播放/下一首，按钮直径 64px，播放按钮 80px）。不显示封面、不显示歌词、不显示粒子。文字琥珀黄 #FBBF24。
1.2 封面 / 唱片
手机圆形唱片 200×200px，边框 6px 黑，中心 60px 封面图。播放时旋转 12s 一圈，暂停停转。背景纯渐变 linear-gradient(180deg,#2a1f4d,#0f0d1f)，不做模糊。
平板圆形唱片 180px，边框 6px 黑，播放时旋转 12s 一圈。横屏竖屏都用圆形，不做方形。
桌面圆形唱片 200px，边框 8px 黑。中心 70px 封面图。播放旋转 12s，暂停停转。背景：封面模糊 blur(30px) brightness(0.4) + 黑色遮罩 50%。
车机不显示封面图，只显示歌曲名文字。驾驶场景不做视觉装饰。
统一规则所有端（手机/平板/桌面）封面形态统一为圆形唱片，播放时旋转、暂停停转，仅尺寸不同。不允许手机端用方形、平板竖屏用方形。
封面缺失统一显示径向渐变占位（粉 #F472B6 → 紫 #8B5CF6）。不显示破图图标。
切歌转场所有端统一：opacity 300ms 淡入淡出。不做滑动、翻页、缩放动画。
1.3 歌词
数据源LRC 格式，[mm:ss.xx] 时间戳。
手机点击封面切换封面视图 ↔ 歌词视图。歌词 16px，行高 2.4，当前行紫色 #A78BFA，其他 #63636F，居中。
平板横屏右侧歌词面板，14px，行高 2.2，左对齐。当前行白色 600 字重。
桌面右栏 280px 歌词面板，14px，行高 2.2。顶部 11px 小标题"LYRICS"。当前行白色 600 字重。
车机不显示歌词。驾驶场景禁止阅读长文本。
滚动规则当前行垂直居中，scrollIntoView({behavior:'smooth',block:'center'})。不做逐字卡拉OK效果。
点击歌词点击任意行跳转到该行时间点播放。手机/平板/桌面必须实现。
翻译行LRC 有翻译则显示在原文下方，字号小 2px，色 #63636F。无翻译不显示空行。
无歌词居中显示"暂无歌词"，14px，#63636F。不做搜索动画。
1.4 视觉模式切换（封面/歌词/粒子/舞台）
控制栏一个"视觉"按钮，点击循环切换 4 种模式。不做弹窗菜单。
模式 0 封面默认。显示唱片/封面 + 模糊背景（桌面）或渐变背景（手机）。
模式 1 歌词桌面：歌词面板扩大占满，唱片缩小到左上 60px。手机：封面区被歌词全屏替换。
模式 2 粒子背景叠加 Canvas 粒子层（见 1.5）。封面/唱片仍在。
模式 3 舞台背景叠加频谱层（见 1.6）。封面/唱片仍在。
车机端不显示视觉模式按钮。车机永远固定在"封面"模式（但车机封面区就是歌名文字）。
持久化当前模式写入 localStorage，下次启动记住。
1.5 粒子背景
渲染Canvas 2D，position fixed，z-index 0（在模糊背景之上、内容之下）。
桌面默认开启，200 粒子，1~2.5px 圆点，色 #A78BFA / #F472B6 随机，透明度 0.3~0.7，每帧位移 0.2~0.5px，边缘反弹。
平板默认开启，80 粒子，其他规则同桌面。
手机默认关闭，设置里手动开启后限 50 粒子 30 帧。
车机强制关闭，不渲染粒子层。
禁止不做粒子连线、不做鼠标交互、不做碰撞检测、不做 WebGL。性能优先。
1.6 舞台（频谱可视化）
数据源Web Audio API AnalyserNode，fftSize=256，取前 N 个频段。
桌面底部铺满 64 根柱子，高度映射 0~200px，色 #A78BFA 透明度 0.6，圆角 2px。
平板底部 32 根柱子，高度映射 0~120px。
手机顶部 24px 高窄条，16 根柱子。不做全屏。
车机不显示频谱。
禁止不做 3D 环形、不做光波涟漪、不做玻璃拟态、不做 VJ 特效。就是简单柱状图。
1.7 循环模式
四态循环按钮循环切换：列表循环 → 单曲循环 → 随机播放 → 关闭顺序播放。
图标列表循环：环形箭头 SVG；单曲循环：环形箭头中间数字"1"；随机：交叉箭头；关闭：环形箭头灰显。
默认首次启动默认"列表循环"。状态写入 localStorage。
车机只保留"列表循环"和"单曲循环"两态，隐藏随机。驾驶场景不随机切歌。
1.8 桌面歌词悬浮窗 仅桌面
形态独立无边框小窗口，初始 400×60px，屏幕底部居中。
内容当前行歌词白色 16px 居中；下一行预览在下方 #63636F 12px。
行为始终置顶。按住歌词文字可拖动。位置写入 localStorage。
开关播放页控制栏"桌面歌词"按钮开关。快捷键 Ctrl+D。
不做不做字体自定义、不做大小调节、不做双行滚动。本版本就是单行当前歌词 + 下一行预览。
1.9 全局快捷键 仅桌面
空格播放 / 暂停
← / →快退 5 秒 / 快进 5 秒
↑ / ↓音量 +5% / -5%
Ctrl+← / Ctrl+→上一首 / 下一首
Ctrl+L循环模式切换
Ctrl+D桌面歌词开关
注意输入框聚焦时不响应快捷键。手机/平板/车机不做快捷键。
1.10 触摸手势 手机 平板
左半屏上下滑调节系统亮度（范围 0.1~1.0）。
右半屏上下滑调节音量（0~100）。
封面区左右滑左滑下一首，右滑上一首。200ms 淡入淡出。
点击封面切换封面视图 ↔ 歌词视图。
双击屏幕播放 / 暂停。
车机车机为触摸屏但驾驶场景不做手势，所有功能必须有物理大按钮可点。
1.11 EQ 均衡器 / 音效预设
入口播放页控制栏"更多"菜单里"音效"项。点开弹出底部面板（手机）或右侧抽屉（桌面）。
预设模式提供 6 个预设：关闭（默认）/ 流行 / 摇滚 / 古典 / 人声 / 低音增强。点击即切换。
手动 EQ5 段均衡器滑块：60Hz / 230Hz / 910Hz / 3.6kHz / 14kHz，每段范围 -12dB ~ +12dB，步进 1dB。
实现方式Web Audio API：BiquadFilterNode 链。预设=滑块自动设值；手动=用户拖滑块实时改 filter.gain。
状态持久化当前预设和手动滑块值写入 localStorage：xinyuan_eq_preset / xinyuan_eq_bands。
车机只保留"关闭 / 人声 / 低音增强"三个预设，隐藏手动滑块。驾驶场景不做复杂调节。
不做不做环绕声、不做空间音频、不做 3D 环绕、不做耳机关配。就 5 段 EQ + 6 预设。
1.12 下载 / 离线缓存
入口歌曲详情页 / 列表项"更多"菜单里"下载"按钮。仅在线歌曲显示，本地文件不显示。
下载位置桌面端：用户选择目录（默认下载目录）。手机/平板：应用私有目录。
下载格式原格式保存（MP3 / FLAC 等），不转码。文件名 = "歌手 - 歌名.mp3"。
封面嵌入下载时同时下载封面图，写入文件 ID3 标签。
下载管理设置页"下载管理"列表：显示已下载/下载中/失败。支持删除已下载文件。
离线播放已下载歌曲自动识别为本地文件，无网可播。列表里用下载图标标记。
状态持久化下载记录写入 localStorage：xinyuan_downloads，value 为 {歌曲hash, 本地路径, 状态}。
播放缓存在线歌曲播放时自动缓存最近播放的 50 首音频到本地临时目录，再次播放直接读缓存不重新请求。缓存上限 500MB，超出自动清理最旧缓存。
视频缓存在线视频播放时边播边缓存当前视频到临时目录，拖动进度条不重复下载。缓存上限 1GB，超出自动清理。
缓存清理设置页提供"清除缓存"按钮，一键清空播放缓存（不删除已下载文件）。
车机车机端不做下载。车机存储小，且驾驶场景不需要离线缓存。
下载增强支持多线程下载、断点续传、下载进度条显示、暂停/继续/取消。失败可重试。

车机横屏全屏视频。控制栏在底部，按钮大（高 56px），只保留播放/暂停/上下首/全屏四个按钮。隐藏循环、适应、画质菜单。
控件自动隐藏播放 3 秒后自动隐藏控件，鼠标移动/触摸时显示，3 秒无操作再隐藏。车机端不自动隐藏（驾驶场景需要持续可见）。
2.2 循环播放
三态循环列表循环 → 单片循环 → 关闭（播完停止）。
A-B 段循环设置菜单"AB循环"按钮。第一次点击设 A 点，第二次设 B 点，之后 A→B 循环。第三次点击关闭。进度条上 A 点绿色标记、B 点粉色标记。
车机只保留"单片循环"开关，隐藏列表循环和 AB。
2.3 画面适应
四种模式按钮循环切换：适应窗口 → 填充 → 拉伸 → 100% 原始大小。
适应窗口默认。视频完整显示，保持比例，黑边填充。
填充视频铺满容器，保持比例，超出裁剪。
拉伸强制铺满，不保持比例（画面变形）。
100%视频原始像素，居中，超出裁剪。
车机固定"适应窗口"，隐藏适应按钮。
2.4 画质调节
显示条件仅在线视频显示。本地视频（file:// / blob）自动隐藏此按钮。
档位菜单：自动 / 360P / 480P / 720P / 1080P / 4K。按数据源返回的档位显示，有几个显示几个。
切换从当前时间点继续播放，不从头开始。按钮文字显示当前档位。
车机固定"自动"，隐藏画质按钮。车机网络环境差，不允许手动切高画质。
禁止不做本地视频滤镜、不做画质增强开关、不做 HDR 切换。
2.5 全屏播放
桌面调用 requestFullscreen()。Esc 退出。双击画面切换全屏。
手机横屏自动全屏（监听方向）。竖屏不强制。
车机车机本身就是全屏横屏，不做全屏切换按钮。
2.6 进度条
样式高 3px，默认 #FFFFFF33，已播 #F472B6，拖拽把手 12px 白色圆点。
桌面端鼠标悬停显示时间文字。本版本不做缩略图预览，只显示时间。
拖拽按住拖动时暂停预览，松手从该点播放。
时间显示左侧"当前时间 / 总时长"，mm:ss 格式，12px，#FFFFFFCC。
2.7 倍速播放
档位菜单：0.5x / 0.75x / 1.0x / 1.25x / 1.5x / 2.0x。默认 1.0x。
车机固定 1.0x，隐藏倍速按钮。
2.8 触摸手势 手机 平板
左半屏上下滑调节亮度。
右半屏上下滑调节音量。
左右滑拖动时显示时间偏移预览（如"快进 10s"），松手跳转。
双击双击左半屏快退 10s，双击右半屏快进 10s，双击中间暂停/播放。
车机不做手势。
2.9 画中画
触发控制栏"画中画"按钮，调用 requestPictureInPicture() API。
行为视频缩为 240×135 悬浮窗，可拖动，切其他 App 继续播放。
支持端桌面浏览器、Android 8.0+、iOS 14+。车机不支持（系统限制）。
2.10 记忆播放位置
存储每 5 秒自动记录当前秒数，key 为视频 URL 或文件路径 hash。
续播下次打开同一视频时弹出 toast"已从 mm:ss 继续播放"，3 秒消失。
清除进度 >95% 后自动清除记录。
2.11 字幕与音轨
字幕延迟设置菜单：+0.5s / -0.5s / 重置。每次步进 0.5 秒。
音轨切换多音轨视频：菜单列出所有音轨，点击切换。
外挂字幕支持加载本地 .srt / .ass 字幕文件。
2.12 视频转音频模式（听视频声音）
入口视频播放控制栏"音频模式"按钮。点击后视频画面隐藏，界面切换为音乐播放器布局，音频继续播放。
切换行为 ① 视频画面暂停渲染，但音频流继续播放；
② 界面从视频播放器切换为音乐播放器布局（封面区+歌词区+控制栏）；
③ 封面位置显示视频首帧截图作为静态封面；
④ 进度条、播放/暂停、切歌、循环、EQ 全部走音乐播放器逻辑。
切回视频音乐播放器界面点"视频模式"按钮，切回视频画面，进度位置保持不变。
移动端手机锁屏后音频继续播放（后台音频），通知栏显示控制。这就是"听视频"场景。
车机车机端视频播放器直接默认音频模式（驾驶场景不看画面）。
音频提取保存音频模式下可点"提取音频"按钮，将当前视频音轨提取保存为 MP3 文件，自动加入本地音乐库。文件名 = 视频标题 + ".mp3"。提取完成后在下载管理页可查看。
视频音频分离下载视频下载时可选"仅下载音频"，不下载视频画面，节省存储。下载后同样加入本地音乐库。

三桌面端（Windows / Linux / macOS）差异说明
UI 完全一致，三个系统共用一套代码（Electron 或 Web）。差异仅在打包和系统集成层：
窗口控制按钮macOS 左上角红黄绿三按钮；Windows/Linux 右上角最小化/最大化/关闭。这是系统原生窗口装饰，应用内不自己画。
媒体键三端都支持硬件媒体键（耳机播放键、键盘媒体键）。
系统托盘三端都最小化到托盘，点击托盘图标显示/隐藏窗口。
文件关联三端都注册音频/视频文件双击打开。
不做差异化不允许 macOS 用毛玻璃、Windows 用 Mica、Linux 用其他主题。UI 完全一致。
iOS / Android 差异说明
UI 一致性iOS 和 Android 用同一套 Web 代码（Capacitor/Cordova 或 WebView），UI 完全一致。
系统差异仅平台 API 层不同：iOS 画中画用 Safari 原生，Android 用 Android 原生 PiP；iOS 后台音频需要 UIBackgroundModes 配置，Android 用 Foreground Service。这些是原生层，不影响 UI。
安全区域iOS 刘海屏需要 safe-area-inset 适配；Android 沉浸式状态栏。两端都用 CSS env() 处理。

专项 Bug 修复（必做，验收卡点）

以下 4 项是现有版本存在的缺陷，纳入开发验收标准，必须一次性解决，不允许遗留。
Bug 1：冷启动加载缓慢，约 10 秒
现象长时间后台休眠或完全关闭后，再次启动 App 加载耗时约 10 秒。
修复要求 ① 资源拆分：首屏 UI、播放器内核、特效资源、歌词解析引擎分优先级异步加载，首屏优先渲染；
② 数据库分页懒加载，本地曲库/收藏/历史不全量一次性读取；
③ UI 静态资源和封面缩略图持久缓存，启动先渲染缓存再后台刷新；
④ 指标：冷启动首屏渲染 ≤ 2 秒。
禁止不允许只加 loading 遮罩掩盖阻塞问题，必须优化加载链路。
Bug 2：移动端返回手势直接回首页，不逐级返回
现象侧滑返回或系统返回键，不管在哪个子页面，直接跳回推荐首页，不遵循页面栈。
修复要求 ① 实现标准路由栈：每打开一个子页面压入栈，返回弹出栈顶；
② 侧滑返回、系统返回键统一读取同一栈；栈空才回首页；
③ 示例：推荐 → 歌单详情 → 播放页，返回顺序：播放页 → 歌单详情 → 推荐。
覆盖页面收藏、本地音乐、下载管理、最近播放、视频子页面全部纳入路由栈。
Bug 3：最近播放记录写入延迟
现象切歌后最近播放列表不立刻更新，刷新后才出现记录。
修复要求 ① 歌曲 play 事件触发时立刻写入内存列表，UI 同步刷新；
② 数据库异步持久化，不阻塞 UI；
③ 同一首歌短时间重复播放不新增多条，更新时间戳置顶；
④ 验收：切歌后最近播放页面即时看到新记录，无肉眼可见延迟。
Bug 4：移动端不支持下载和本地扫描（沙盒限制）
现象移动端提示"暂不支持下载"、无法扫描本地歌曲，仅桌面可用。
修复要求 ① 安卓/iOS 接入原生存储权限，移除"移动端暂不支持"提示；
② 本地音乐页面完整开放添加文件夹扫描、重新扫描；
③ 下载管理页面移动端完整可用；
④ 权限拒绝时友好提示，不崩溃。
车机保持不开放下载和本地扫描。
