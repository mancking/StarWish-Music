# 星河音乐 v2.3.5 发布说明

> 发布日期：2026-10-24 ｜ 对齐《全端播放模块开发规格书 v4.11》 ｜ 上一版：2.3.4

## 简介

v2.3.5 按《全端播放模块开发规格书 v4.11》完成全端播放模块的整轮开发：播放内核、视频/MV 聚合、源市场治理、多端差异与大批 Bug 修复一次到位，版本号保持 2.3.5 不迭代。

## 主要更新

- **播放体验**：卡拉OK 逐字歌词；播放队列与定时关闭、倍速重启保持；下载断点续传（.part + Range）；亮度/音量弧形指示器；左右滑切换封面↔歌词、上滑唤起队列（手势全家桶重构）
- **视频/MV**：MV 多音源聚合（网易云/QQ/酷狗/酷我 + 外部源协议）、`/mv/:source/:id` 统一播放器、播放页 MV 按钮、音频提取保存 MP3、截图、外挂字幕（SRT/ASS + 延迟）、弹幕设置全参数生效、自动连播、进度缓冲灰层、长按 1.5x
- **页面**：搜索历史 + 歌单/歌手聚合 Tab；本地音乐歌曲/歌手/专辑分组；歌单收藏；发现页内嵌分类 chips（含语种）；桌面首页按规格重做
- **源治理（0.8~0.10）**：随包仅自研源（第三方外置，安装包不再携带混淆/带密钥脚本）；沙箱请求域名白名单；取链 30s 预算 + 前 3 候选竞速 + 429 熔断；音源调试日志；统一源市场（音源/插件/视频源，多镜像 + 原子安装 + 一键回滚 + 可更新角标）
- **局域网同步**：桌面主机 + 手机/车机手输 IP + 配对码，收藏/最近播放/设置双向 LWW 同步
- **多端**：车机全局琥珀黄大字样式与退出入口、进度条禁拖、返回兜底；平板四档断点；首启三屏引导与无源提示条
- **修复**：规格书 Bug 修复专项大批落地（#6/7/9/11~13/15~21/25/30~42/46~55/63/66~82/97~110 等）、移动端取链超时/换源竞态/队列恢复、桌面崩溃与静默失败治理、无障碍与布局清理

## 说明

- 第三方音源不再随包分发（合规要求）：请到「设置 → 源市场 / 导入音源 / 订阅源」获取，或手动启用内置完整音源
- 五端产物：Windows（便携/安装）、Linux（AppImage/deb）、macOS（x64/arm64）、Android（APK）
- 无广告、无埋点、不采集个人信息
