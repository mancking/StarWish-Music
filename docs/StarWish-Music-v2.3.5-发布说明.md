# 星河音乐 v2.3.5 发布说明

> 发布日期：2026-10-23 ｜ 代号：全端播放模块 v2.7 对齐
> 上一版本：2.3.4（2026-10-22）

## 简介

v2.3.5 是一次**播放内核级**的版本。本版依据《星河音乐 · 全端播放模块开发规格书 v2.7》重做了「播放」这一件事：
把播放页按 **手机 / 平板 / 桌面 / 车机** 四端重新分档，视觉模式、粒子、频谱、音效均衡器全部改为按端降级；
音频链路从「单个 `<audio>` 直出」升级为 **Web Audio 图（音源 → 5 段 BiquadFilter → AnalyserNode → 输出）**，
因此有了真正可用的 **EQ 均衡器** 和 **实时频谱**；视频侧补齐 **AB 段循环**、**画中画**、进度记忆键统一；
并修复了「最近播放写入延迟」等反馈项。

一句话：**这一次，播放器的「听感」和「四端形态」都对上了规格书。**

## 版本亮点

### 一、四端分档（规格书 0.1 / 0.3）

- 新增 `src/platform.ts` 作为唯一的端判定与降级入口：
  - **车机**（UA / `?platform=car` / `xinyuan_car=1`）→ 手机 → 平板（600~1024）→ 桌面（≥1024），平板 ≥900 横屏走两栏
  - 性能档位：粒子 **200 / 80 / 50 / 0**，封面模糊 **30 / 12 / 0**，频谱柱 **64 / 32 / 16 / 0**，唱片旋转仅桌面与平板
  - 低性能判定（`hardwareConcurrency < 4`、移动 UA、省电开关）统一收敛到 `lowPerf`
- 持久化键统一为 **`xinyuan_` 前缀**（`visual_mode` / `loop_mode` / `lyrics_panel` / `desktop_lrc_pos` / `resume_<hash>` / `low_perf` / `platform` / `eq_preset` / `eq_bands` / `downloads`），旧键读取时自动迁移。

### 二、播放页四端形态（规格书 1.1 ~ 1.4）

- **桌面**：两栏（左唱片 200px + 控制，右歌词 280px），封面模糊按档位生效
- **手机**：单列，方形封面 200px 圆角 12，点封面切歌词，顶部 24px 窄条频谱（16 柱）
- **平板**：两栏（唱片 160px + 右侧歌词）
- **车机**：新增 `src/pages/CarPlayer.vue` —— 横屏大字（歌名 28px / 歌手 18px，琥珀黄 `#FBBF24`），三键 64px / 播放 80px，**无封面、无粒子、无频谱、无手势**
- **视觉模式 4 态**：封面 → 歌词 → 粒子 → 舞台频谱，按钮循环切换并写入 `xinyuan_visual_mode`；旧的 `cinema` / `podcast` 值自动映射为 `cover`，不再丢失用户选择
- 循环模式 **四态**（列表 / 单曲 / 随机 / 关闭）持久化到 `xinyuan_loop_mode`，车机只保留两态

### 三、音频层：EQ 均衡器 + 实时频谱（规格书 1.6 / 1.11）

- **桌面**：音频图建在隐藏播放进程（`electron/player-host.ts`）里，`MediaElementSource → 5×BiquadFilter → AnalyserNode(fftSize=256) → destination`，频谱每 60ms 回传 64 段到界面（新增 IPC `player:spectrum` / `player:eq`）
- **移动端**：同源 `/swmedia/` 代理下按需建图（有 EQ 或频谱订阅时才接图，避免挂起 AudioContext 静音），`src/mobile/player.ts` 新增 `setEqBands()` / `subscribeSpectrum()`
- **EQ 面板**：6 个预设（关闭 / 流行 / 摇滚 / 古典 / 人声 / 低音增强）+ 5 段滑块（60 / 230 / 910 / 3.6k / 14k Hz，±12dB，步进 1），写 `xinyuan_eq_preset` / `xinyuan_eq_bands`；**车机仅 3 个预设且无滑块**
- 频谱组件 `SpectrumBars.vue`、粒子组件 `ParticleField.vue`（Canvas2D，无连线 / 无鼠标交互 / 无 WebGL）

### 四、视频（规格书 2.x）

- **AB 段循环**：桌面与移动端视频播放器均新增 —— 第一次点设 A（绿），第二次设 B（粉），第三次清除；播放头到达 B 点自动回跳 A
- **画中画**：移动端新增入口（Android 8+ / iOS 14+，不支持时给出明确提示）
- **进度记忆**：键名统一为 `xinyuan_resume_<bvid>_<cid>`，播放超过 95% 自动清除，旧键仍可回读
- 六档倍速、画面四模式、全屏、手势、字幕 / 音轨等沿用既有实现

### 五、Bug 修复（规格书 4.x）

- **4.3 最近播放写入延迟**：播放一开始就立即写入内存并刷新列表（`App.vue` 监听 `player.state.status`），数据库异步落库，回到「最近播放」不再看到过期数据
- **4.2 返回手势**：沿用并核对逐级回栈（弹层 → 上一级路由 → 根路由双击退出）
- **4.1 冷启动**：维持「先挂载骨架、并行初始化」的启动顺序，本地曲库改为 **DB 分页懒加载**（每页 200 条 + 「加载更多」），首屏不再一次性渲染上千行
- **4.4 移动端本地音乐**：新增 `SwBridge.scanLocal` 扫描系统媒体库（MediaStore），音频由 `SwMediaClient` 的 `/swlocal/?id=` 支持 Range 流式回放；权限被拒时给出「音乐和音频」权限引导，不再显示「暂不支持」

### 六、桌面快捷键（规格书 1.9）

`Space` 播放 / 暂停 · `←/→` 快退快进 5s · `↑/↓` 音量 ±5% · `Ctrl+←/→` 上 / 下一首 · `Ctrl+L` 切循环 · `Ctrl+D` 桌面歌词 · `Ctrl+K` 搜索；输入框聚焦时不响应。

### 七、其余对齐项（规格书 1.8 / 1.12 / 3.x / 4.4）

- **1.8 桌面歌词窗**：重做为固定 **400×60** 底部居中悬浮窗 —— 当前行 16px 白色居中、下一行 12px 灰、毛玻璃底、置顶且可拖动，位置写入 `lyric-win.json` 并在下次启动复原
- **1.12 下载**：文件名统一「歌手 - 歌名.扩展名」；下载完成后写入 **ID3v2.3** 标题 / 歌手 / 专辑 / 封面（新增 `electron/core/id3.ts`），并自动并入本地曲库；新增 **暂停 / 继续**
- **3.1 推荐首页**：日期 13px、问候语 24~28px/600、胶囊搜索框（回车跳搜索页）、底部右对齐半透明星河 Logo 卡片
- **3.2 我喜欢的音乐**：移除 App 图标，改为渐变心形封面 + 「收藏夹 · N 首 · 保存在本地」
- **3.5 下载管理**：移动端改为「保存到系统音乐库」说明，进行中任务支持暂停 / 继续

## 升级说明

- **版本号**：`2.3.4 → 2.3.5`（Android `versionCode` 由 semver 自动推导为 `2003005`）
- **覆盖安装即可**，数据库结构未变更，歌单 / 收藏 / 历史全部保留
- **本地存储**：本版开始写入 `xinyuan_` 前缀键，旧的 `sw.stage` / `sw.mvprog:*` 读取时兼容迁移，无需手动清理
- **音频链路变化**：若某些极端环境（例如系统禁用了 Web Audio）下出现无声，可在设置中把 EQ 设为「关闭」并重启播放器，频谱随之关闭
- **Android 权限**：本版新增「音乐和音频」读取权限（Android 13+ `READ_MEDIA_AUDIO`，Android 12 及以下 `READ_EXTERNAL_STORAGE`），仅在「扫描系统音乐库」时申请；拒绝后可在 系统设置 → 应用 → 星河音乐 → 权限 中重新开启
- **桌面歌词窗**：窗口改为固定 400×60，首次启动位于屏幕底部居中，拖动后的位置会被记住
