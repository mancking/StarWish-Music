> 平台：**Windows 10 / 11（x64）桌面版；Android（手机 / 车机）**
> 架构：**Electron 31 + Vue 3.5 + TypeScript + SQLite**（桌面）/ **Capacitor 6 WebView + 同一 Vue 代码库**（移动端）
> 本文档合并并取代 `StarWish-Music-正式开发文档.md`（v3.0 八端方案）与 `v1.1-修复与迭代开发文档.md` 中的需求部分。
> 本文档 v2.1 起补充 Android 支持（手机端与车机端共用同一签名 APK）；Linux / macOS 安装包由 GitHub Actions 云构建产出，iOS 因缺少 Apple 开发者证书暂不交付。

## 2. 技术架构

### 2.1 进程模型

```
主进程（Node.js）
├─ 窗口 / 托盘 / 全局快捷键 / 单实例
├─ IPC 路由（sw:invoke）与错误归一化
├─ 音源沙箱（lx-music v2，vm）
├─ 平台接口、聚合搜索、取链降级、自动换源
├─ SQLite（sql.js）持久化、缓存管理
└─ 播放队列权威状态（PlayerService）

渲染进程（Vue 3 + Pinia）
├─ 页面 / 组件 / 主题 / 歌词渲染
└─ 只通过 preload 白名单与主进程通信

音频宿主（隐藏的独立渲染进程）
├─ <audio> 解码与播放
├─ 淡入淡出、缓冲看门狗
└─ 与 UI 完全隔离，崩溃自动重建

桌面歌词窗口（独立渲染进程）
└─ 透明置顶、鼠标穿透锁定
```

**为什么这样拆**：UI 重渲染/路由切换不影响音频；音频宿主崩溃不影响界面；任一进程异常都有兜底与日志。

### 2.2 目录结构

```
app/
├── electron/            主进程
│   ├── main.ts          生命周期、协议、托盘、快捷键、崩溃兜底
│   ├── ipc.ts           统一 IPC 路由与错误文案
│   ├── preload.ts       contextBridge（invoke + 事件白名单）
│   ├── player-host.ts   音频宿主
│   ├── windows.ts       主窗口 / 音频宿主 / 桌面歌词
│   └── core/            http / lx-host / providers / bili / music-service
│                        cover / media / db / library / player-service
│                        recommend / settings / paths / log
├── src/                 Vue 渲染层（pages / components / stores / styles）
├── shared/              共享类型与 LRC 解析
├── sources/             内置音源脚本（lx-music 协议）
├── resources/           品牌图标、封面、托盘图
└── scripts/             构建、图标生成、冒烟测试
```

### 2.3 自定义协议

| 协议 | 作用 |
|---|---|
| `swcover://covers/r/<url>` | 远端封面：主进程注入 Referer 抓取、落盘缓存、失败回退 |
| `swcover://covers/l/<file>` | 本地内嵌封面 |
| `swmedia://stream/?u=<target>` | 音频/视频代理：本地文件手写 Range；远端透传 Range 并注入 Referer / Cookie |

渲染层不直连任何平台 CDN，CSP 仅放行 `self / swcover / swmedia / data / blob`。

### 2.4 数据模型

```sql
songs(id PK, source, song_id, name, singer, album, duration, pic, local_path, qualitys, extra, created_at)
playlists(id PK, name, pic, description, source, remote_id, kind, created_at, updated_at)
playlist_song(playlist_id, song_id, pos, added_at, PK(playlist_id, song_id))
favorites(song_id PK, added_at)
play_history(id PK AUTOINCREMENT, song_id, played_at, ms)
play_count(song_id PK, count, last_at)
settings(key PK, value)
```

写入策略：600ms 防抖 + 临时文件原子替换，退出前强制落盘。

## 3. 功能清单（必须全部保留）

### 3.1 首页（个性推荐）

### 3.2 发现音乐

- 推荐歌单：22 个标签筛选、最热/最新排序、分页加载。
- 排行榜：按音源分组（A/B/C），动态拉取真实榜单（100+），左侧榜单树 + 右侧歌曲表。
- 最新音乐：新歌列表。
- 平台歌单导入：粘贴分享链接自动识别来源，保存为本地歌单。

### 3.3 搜索

- 聚合多个音源与插件，去重后按相关度排序（原名/歌手命中加权，翻唱/DJ 降权）。
- 平台过滤（全部 / 音源 A / B / C）。
- 一键播放全部、加入队列。

### 3.4 播放页

- 黑胶唱片 + 真实封面；歌词舞台 / 粒子舞台 / 电影镜头 / 播客 DJ 四态。
- 歌词：逐字高亮、翻译对照、点击跳转、±500ms 偏移、来源显示。
- 队列抽屉：拖拽排序、点击播放、移除、清空。
- 控制：随机/循环/单曲、上一首/下一首、音质切换、收藏、音量、倍速（0.75–2×）、定时关闭。
- 封面主色提取 → 全站强调色自适应。

### 3.5 我的音乐

- 我喜欢的音乐（红心，落库）。
- 本地音乐：文件夹扫描、标签/时长/内嵌封面/内嵌歌词、筛选、播放。
- 最近播放：按歌曲去重，清空历史。
- 我的歌单：新建、重命名、删除、添加/移除歌曲。
- 平台歌单导入与收藏。

### 3.6 视频 / MV（内置播放器 + 分集）

- 独立一级页面，卡片网格。
- 点击进入**内置播放器页面**（非弹窗外置）：16:9 视频、标题/作者/播放量。
- 右侧「分集」列表：展示全部分 P（P1…Pn）与时长，点击切换 cid 播放。
- 超长合集（>1 小时）先提示选集，避免直接加载数 GB 文件卡死。
- 「听音频」：以当前分 P 作为音频加入播放队列。
- 同作者更多视频推荐。

### 3.7 系统能力

- 托盘：显示/隐藏、播放控制、桌面歌词、退出。
- 全局快捷键：`Ctrl+Alt+P` 播放暂停、`Ctrl+Alt+←/→` 上下首、`Ctrl+Alt+L` 桌面歌词。
- 媒体键：播放/暂停、上一首、下一首。
- 关闭到托盘、窗口尺寸/最大化记忆、单实例。
- 桌面歌词：透明置顶、锁定穿透、字号/偏移可调。
- 深色/浅色/跟随系统；强调色自动取色或自定义。
- 日志文件（按天滚动，保留 7 天）与崩溃兜底。

### 3.8 设置（8 个分类）

1. **外观主题**：主题模式、强调色（自动/自定义）、界面动画、粒子舞台。
2. **播放**：默认音质、自动换源、失败跳过、淡入淡出、过渡时长、播放速度、定时关闭、记住进度。
3. **歌词**：桌面歌词、锁定、字号、偏移校准、当前来源。
4. **音源与插件**：启停、导入（URL/本地）、查看源码、移除、恢复内置、视频源扫码登录。
5. **本地音乐**：音乐文件夹、扫描、启动扫描、曲库统计。
6. **网络与缓存**：**缓存目录更改/打开/恢复默认**、封面缓存、媒体缓存、清理、数据目录。
7. **快捷键**：完整列表。
8. **关于**：版本、运行时版本、数据库统计、日志目录。

### 3.9 音源管理原则

- 内置音源与用户导入音源**一视同仁**：可启停、可移除、可恢复。
- 移除内置音源只记录标记，不删除安装文件；「恢复内置音源」一键还原。
- 用户导入支持在线链接与本地 JS 文件，校验 lx-music 协议特征。
- 设置页可查看任意音源源码，作为开发范本。

### 3.10 品牌与内容呈现

- 界面不出现任何官方音乐软件名称、Logo 或“官方”暗示。
- 所有歌曲、歌单、榜单、歌词、封面数据均标注为「在线音源 / 本地音源 / 音源插件」。
- 音源平台在界面中统一以「音源 A/B/C…」呈现，具体平台信息仅在音源脚本内部使用。

## 4. 核心机制

### 4.1 播放链路

```
点击歌曲 → 主进程 setQueue → resolveUrl（24bit→flac→320k→128k 降级）
        → 逐音源取链 → 下发 swmedia 地址给音频宿主
        → 失败：自动换源（去括号版本匹配，最多 4 个候选）
        → 宿主 error：同曲换源重试 2 次 → 跳下一首
        → 连续 3 首失败：暂停并提示检查音源
```

- 位置每 500ms 上报，UI 用 rAF 插值，进度条平滑。
- 25 秒无进度且缓冲不足判定卡死，主动重试。
- `ended` 时写入播放历史与播放次数。

### 4.2 封面链路

1. 歌曲自带封面（已转 `swcover://`）。
2. 音源插件 `pic` action。
3. iTunes Search 兜底（100→600px）。
4. 渐变 + 首字符占位。

内存 LRU 60 张 + 磁盘缓存（可自定义目录）。

### 4.3 歌词链路

1. 本地：内嵌歌词 → 同目录 `.lrc`；纯音乐不猜测。
2. 在线：插件 → 平台官方 → 同名 + 时长匹配。
3. 多候选解析后按有效行数择优；内存缓存 300 首。
4. 支持 LRC/QRC/YRC 时间标签、翻译行、逐字标签。

### 4.4 音源沙箱

- `vm` 上下文提供 `lx.request/send/on/env/utils/EVENT_NAMES`。
- 无 DOM、无 `require`、无文件系统；请求统一走宿主 HTTP（超时 + 重试 + 按域名限流）。
- 单个音源加载失败只标记自身，不影响其他音源。
- 搜索聚合「到点即返回」，慢音源不阻塞 UI。

## 8. 已知边界

- 版权受限歌曲可能所有免费音源都无法取链，此时给出明确提示。
- 平台接口随时可能变更；原生接口失败由插件兜底。
- 超长视频合集（数小时）受浏览器解码与带宽限制，建议选择分 P 播放。
- 播客内嵌播放器：精选入口直接进入应用内播放页，单集全部在播放器内播放，不跳转浏览器。
- 识曲、DLNA、均衡器等需要额外硬件/服务的能力不在本版本范围内。
