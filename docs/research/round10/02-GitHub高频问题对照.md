## 三、备注与不重复声明

- **与 round9 的边界**：round9 T1/T2/T3 已覆盖「Android 无 MediaSession/前台服务」，本轮 N1 聚焦「WebView autoplay 策略未关闭」——这是 Web 层播放链路问题，不依赖原生 MediaSession，车机 WebView 场景独立成立；N10 是桌面 audio host 唤醒恢复，与 T3 蓝牙/来电不同维度。
- **N3 是本轮最高优先级**：LX Music 官方 FAQ 把它单列成「Windows 全曲加载错误」条目（S1），星河用户开代理后大概率踩同样的坑；修法明确（http.ts:212 改 net.fetch），改动量小。
- **N4/N9**：主窗和歌词窗的跨屏校验不对称（歌词窗有、主窗无），建议合并修一次，都接 `screen.on('display-metrics-changed'/'display-removed')`。
- **无对应实现/风险低**：
  - 「播放列表云同步冲突」：全仓无 WebDAV/云盘歌单同步模块（grep `webdav|syncPlaylist|cloudSync` 0 命中业务代码），风险低。
  - 「MV 解析失败」：`electron/core/providers.ts:1372-1397` 已实现 B 站 `playurl` 多档 qn + `platform=html5` 兜底，且 round9 未列；无新增外部高频证据，暂不单列。
  - 「HiDPI 字体模糊」：Electron 官方 FAQ 建议给 BrowserWindow 设 `backgroundColor` 解决 sub-pixel AA 模糊——`electron/windows.ts:43` 已设 `#0b0d12`（round9 Bug60 提到与 splash 色差，待统一色值），本轮不重复。
