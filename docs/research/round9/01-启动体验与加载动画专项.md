## 二、启动动画规范章节（交付基线）

1. **时长/节奏**：品牌呼吸动画 splash-breathe 1.6s 循环；双点闪烁 splash-blink 1.2s；最短展示 800ms（防止一闪而过）；退场 fade-out 固定 400ms；元素 remove 延迟统一 650ms。
2. **明暗适配**：splash 底色使用统一令牌——深色 #0b0d12、浅色 #f7f8fb，与 Electron windows.ts:399 setBackgroundColor、Android drawable/splash 底色三者 hex 完全一致；浅色适配走 `@media (prefers-color-scheme: light)`（index.html:13-33 已有同款模式，全端复用）。
3. **性能降级**：`@media (prefers-reduced-motion: reduce)` 时关闭 breathe/blink 动画，仅静态 logo+名称；低端机判定 `navigator.hardwareConcurrency<=4 || (deviceMemory||4)<=2` 时 JS 主动移除动画 class，保留静态 splash。
4. **超时兜底**：桌面硬超时 6s、移动/车机 8s 强制 hideSplash；超时后进入界面顶部出现提示条「加载较慢，部分音源可能未就绪」。
5. **原生 splash ↔ Web splash 衔接**：原生侧保持显示直到 Web 首帧 #splash 绘制完成（Capacitor 用 @capacitor/splash-screen 主动 hide，fadeOut 300ms）；原生 drawable 的 logo 位置/尺寸/底色与 Web splash 对齐，消除交接跳变。
6. **进度提示/文案规则**：不做假进度条；仅当 init 超过 1.5s 未完成才显示文案「正在加载音源与本地曲库…」；文案字号不超过主标题 60%，避免喧宾夺主。

## 四、重点缺口 ①-⑥ 逐条结论

1. **① 原生→Web 衔接白闪**：styles.xml:19 用 Theme.SplashScreen 静态 drawable，未装 @capacitor/splash-screen、无 hide() 调用，交接时机不受控，Android12+ 存在白闪风险 → 安装插件、mount 后主动 hide、配色对齐。
2. **② #splash 无超时兜底**：桌面 src/main.ts:82-83 await ui.init()、移动 :89-97 Promise.all().finally()，init 挂起则 splash 永驻 → 6s/8s 硬超时强制退场。
3. **③ 车机 WebView 无 splash**：web/index.html 零 splash → 内联纯 CSS splash 注入构建产物。
4. **④ Electron 窗口白屏期**：windows.ts:41 show:false + ready-to-show + 8s 兜底已无白窗；缺口仅在浅色主题窗底 #f7f8fb 与 splash 底色 hex 未对齐 → 统一配色令牌。
5. **⑤ installBridge 阻塞首帧**：main.mobile.ts:37 await 早于 :70 mount，握手慢直接拉长白屏空档 → 800ms 超时竞态，先 mount 后挂桥。
6. **⑥ 450ms vs 0.4s 一致性**：50ms 余量在低端机不足 → 统一 650ms remove 延迟常量。
