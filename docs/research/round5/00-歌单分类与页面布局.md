## 〇、歌单分类筛选「功能有效性」验证结论（代码级，非推测）

核验文件：`D:\music\app\src\pages\Discover.vue`（桌面）、`src\pages\mobile\Discover.vue`（移动）。

- **桌面筛选链路有效**：点击分类标签 → `selectCat()` 关闭弹层 → 写路由 `cat` → `loadPlaylists(1)` 携 `catId`（名称→id 映射，QQ 接口需 id）重拉歌单；带 SWR 后台缓存（30s 防抖、切换强制刷新）、请求序号 `plReqSeq` 防串台、满 30 条判下一页的真分页；切音源并行拉标签+歌单并弃过期结果。
- **移动筛选链路有效**：分段 tab 吸顶 + 分类横滑胶囊，切换分类/音源立即骨架反馈，请求序号防串台，外部入口（首页「按心情听」等）带 query 进入时同步补数据。
- **现存缺口（本轮需整改）**：① 桌面为「折叠标签弹层」（浮层 max-height 250px 滚动）而非内嵌 chips，且不吸顶；② 四组标签（热门标签/专区/主题/心情）缺「语种」整组；③ 仅单选，无多选或 t1×t2 两级组合；④ 移动胶囊平铺 14 项无分组；⑤ 酷我/酷狗/咪咕无标签接口时入口隐藏（`tagSupported=false`），内嵌化后需给出无标签音源的降级方案（隐藏 chips 行或仅显示「全部」）。

### 内嵌式歌单分类 chips 量化布局规范（可直接写 CSS）

- **容器与吸顶**：歌单页顶部内嵌条带 `position: sticky; top: 0`（移动端 top 需让位已吸顶分段 tab，即 top:40px）；背景跟随主题 `var(--bg)`；初始无阴影，滚动越过条带后追加 `border-bottom: 1px solid var(--border)`（或 `box-shadow: 0 1px 4px rgba(0,0,0,.06)`）；z-index:10 低于全局播放条。移动端条带总高 ≈ tab 40px + chips 行（32+16）≈ 88px；桌面无 tab 行，条带高约 46px。
- **四组标签呈现（推荐两行/三行结构）**：第一行为组切换 chips（全部/语种/风格/场景/心情）；第二行为当前组的具体标签 chips 横滑单行。组切换 chips：高 28px、padding 0 10px、圆角 14px、字号 12px、间距 6px、浅灰底 `rgba(128,128,128,.12)`；组内标签 chips：高 32px、左右内边距 12px、字号 13px、圆角 16px（全胶囊）、水平间距 8px、容器左右留边 16px。桌面放宽为小圆角矩形：高 30px、padding 0 12px、圆角 8px、字号 12.5px、间距 8px；宽度充足时第二行允许 wrap 换行（行距 10px），不必横滑。
- **选中态**：选中 = 背景 `rgba(品牌色,.12)` + 字色品牌色 + 1px 描边 `rgba(品牌色,.30)`；未选中 = 透明底、无边框、灰字 `var(--text-2)`。维持单选，切换组时组内选中重置为「全部」。
- **横向滚动**：`overflow-x:auto; overflow-y:hidden; scrollbar-width:none;` + `::-webkit-scrollbar{display:none}`；移动端加 `-webkit-overflow-scrolling:touch`；点击标签后 `scrollIntoView({inline:'center',behavior:'smooth'})` 居中。
- **与音源/排序合并**：页头行（第一行）= 音源下拉（高 30~34px、padding 0 12px、圆角 8px）+ 最热/最新 segmented（高 30px、padding 0 10px、圆角 8px）靠右 + 导入按钮最右；第二行 = 组切换 chips；第三行 = 组内标签横滑。分类参数沿用现有 catId 名称→id 映射与点击即筛选逻辑，仅把 `.tag-popup` 浮层改为内嵌条带，SWR 缓存与请求序号防串台机制不动。
- **语种组建议**：华语/欧美/日语/韩语/粤语/小语种（对齐网易云语种组）。

对标来源：网易云歌单广场（语种/风格/场景/情感/主题 5 组 70+ 标签，人人都是产品经理/网易云 6.0 说明）；QQ 音乐分类歌单页 t1×t2 两级单选（y.qq.com/n/ryqq_v2/category）；QQ 音乐 Mac 歌单广场分类面板（musicmac/v6/playlist）；LX Music 桌面版（lxmusic.toside.cn，Electron+Vue 弹层式取舍）。

## 六、整合要点（供下一轮落地）

1. **歌单分类内嵌化**是用户硬需求：把桌面 `.tag-popup` 浮层改为歌单页顶部 sticky 内嵌条带（三行：音源/排序行 + 组切换 chips + 组内标签横滑），移动端并入现有吸顶结构（top 让位 40px），补「语种」整组；保留现有筛选链路（catId 映射/SWR/防串台/真分页）不动。
2. **布局错乱根因汇总**：桌面=断点缺失（仅 1300 单断点）+ 间距变量不统一（gap 20×18 与页边距混用）+ 无最小窗口约束；移动=Safe Area 缺失（TabBar 被 Home Indicator 遮挡、末行被 MiniPlayer 遮挡）+ 页面 padding 混排（24px/12px）+ 歌曲行高未与桌面分离。两者均给出量化修复值。
3. **第五轮功能补全优先级建议**：桌面 D4 局域网同步 + D1 歌词翻译；移动 M1 小组件 + M5 耳机拔出暂停；平板 T4 侧栏常驻 + T2 分屏；车机 C1 蓝牙自动切模式 + C2 语音。均标注了真实来源，可进入规格书下一版排期。
