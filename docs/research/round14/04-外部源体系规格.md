## 三、外部源体系规格（写入规格书 0.9，要点）

### 0.9.1 框架与源边界（不丢失框架内容的前提）
- **框架**（≈70% 功能，永不被源覆盖/卸载）：本地音乐扫描/播放器内核/音量·播放模式·倍速·定时/EQ10 段/频谱/下载管理框架/设置·主题/封面缓存协议/播放缓存/壁纸引擎/桌面歌词·任务栏歌词/WebDAV/代理/B站账号登录/数据目录迁移/启动就绪门控。
- **原生接口层**（半依赖，不算导入音源）：首页推荐/发现页歌单·榜单·新歌/私人电台（providers.ts 硬编码 wy/qq/kg/kw/mig）。
- **外部源层**（强依赖）：lxHost 音乐音源（lx 协议）+ mfHost 插件（MusicFree 协议）+ video 源（未来，C-24）。
- 边界规则：外部源只能被「启用/禁用/删除/更新」，任何操作不触碰框架模块；卸载全部源后应用仍完整可用（回退路径=框架内容）。

### 0.9.2 导入规范与持久化（四条链路）
- 本地 JS：JSDoc 头 @name/@version 契约校验 + 512KB 上限 + **沙箱试跑拿到 platforms 成功才写盘**（N25）。
- URL：限 https + 最多 3 次重定向 + 9MB 上限（对齐落雪 utils.ts:81-89）。
- 插件市场：manifest `{plugins:[{name,url,version}]}` + hash 去重 + 多镜像竞速（N24 桌面补到 5 镜像）+ 安装后 enabled:true（N26）。
- 订阅：列表 `{name,url,updatedAt,count}` + 每条「立即刷新」（C-25）+ 移除时询问卸载（F-26）。
- 持久化链路：写盘 `<userData>/sources/` 或 `plugins/` → 内存 reload → broadcast sources:changed → 渲染层消费（Bug 122）→ 重启自动加载（文件即持久化）；迁移清单含 plugins（N27）。
- 原子更新：先写新再删旧 + hash 去重 + 失败回滚（对齐 MusicFree 降级保护 / any-listen 事务式更新）。

### 0.9.3 首次启动体验（量化）
- DB 标记 `onboarded=false` → 首次启动进 `/welcome` 引导页（1~3 屏：①「应用已内置 X 个音源」②「音源失效可从插件市场一键安装」→/settings?sources=market ③「扫描本地音乐」→/settings?sources=local）；完成后 onboarded=true。
- 无源常驻 banner：`sources.filter(s => !s.loadError && s.enabled).length === 0` 时首页顶部常驻「当前无可用音源，点此导入」→设置。
- 空态即引导：搜索空态/发现页空态给「去导入」CTA（对齐 MusicFree NO_PLUGIN 空态范式）。
- 移动端对等：F-22/F-23 是引导前置条件。

### 0.9.4 实时更新机制
- 导入即时生效：sources:changed 消费者（搜索页平台 Tab Bug 123 联动、player store 失效缓存 Bug 122）。
- 重启自动加载：文件即持久化（已实现）；plugins 目录入迁移（N27）。
- 订阅刷新：启动后距上次 >24h 自动刷新（MusicFree bootstrap.ts:206-224 口径）+ 手动「立即刷新」；同域错峰 ≥2s、并发 3~5（FreshRSS 口径）；错过周期优先补拉。
- 版本更新原子性：先写新再删旧 + 失败回滚 + hash 去重（不重复安装）。

### 0.9.5 多源冗余与降级
- 多源并用：搜索聚合 allSettled（已证）+ 取链候选竞速择优（0.8.2）+ 歌词/封面多源。
- 跨平台取链降级（F-24）：候选扩大到所有支持 musicUrl 的音源，音源侧按歌名相似度匹配；resolveUrl avoidSources 完整传播。
- 429 停手 + 15s 超时（0.8.2 已有，保持）。
- 插件参与播放（Bug 120）：主链 mfHost 与 lxHost 并列聚合，任一可用即保障功能。

### 0.9.6 视频/MV 源外部化
- lx-host 增加 `videoSearch / videoInfo / videoParts / videoUrl` 分发（C-24）；music-service 先问音源层，fallback B 站。
- 外部视频源插件抽象对齐 MusicFree bilibili 插件（视频=album、fnval:16 DASH 抽 audio[] 按带宽映射音质、headers 透传防盗链）。
- Mv.vue 增加视频源选择（与 3.10 源 Tab 联动）；B 站保留为默认兜底源。

### 0.9.7 本期做 / 二期做 / 不做（验收 = 7.0「外部源体系验收」）
- 本期：Bug 120/121/122/123、C-24/C-25、N24/N25/N26/N27、F-21~F-26 全部（16 项）。
- 二期：订阅 24h 自动刷新增强（健康度联动）、视频源插件市场（有生态后）、B 站 wbi 签名+登录态注入（round13 二期项）。
- 不做：不内置任何第三方平台音源（合规：LX 2023-10 移除内置源、MusicFree 官方仓库 1.9k star 后因告知函下架国内厂商源）；不引入重型插件框架（Extism WASM 等）。
