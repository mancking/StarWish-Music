# 内置音源

本目录存放随应用加载的 lx-music 协议音源脚本。应用启动时会读取这里的所有 `.js` 文件并注册为可用音源。

## 仓库内包含

| 文件 | 说明 |
|---|---|
| `starwish-unified.js` | 自研聚合音源：搜索 / 取链 / 歌词 / 封面 |
| `starwish-bilibili.js` | 视频音源：视频分 P 解析、音频提取（需登录解锁高清晰度） |

## 关于第三方音源

第三方社区音源（各种聚合脚本）版权与维护权归各自作者所有，本仓库**不随源码分发**。你可以在本地放入 `sources/` 目录，或通过应用内「设置 → 音源与插件 → 导入音源」加载：

- 在线链接（http/https）
- 本地 `.js` 文件

导入后会复制到用户数据目录 `%APPDATA%\StarWish\sources`，与内置音源一起管理。

## 管理方式

- **启停**：设置页开关，停用后不参与搜索与取链。
- **移除**：内置音源移除只记录标记，不删除安装文件，可随时「恢复内置音源」。
- **查看源码**：设置页点击铅笔图标，可直接参考实现。
- **开发自己的音源**：见 [`docs/音源开发指南.md`](../../docs/音源开发指南.md)。

## 目录优先级

1. 安装目录 `resources/sources`（打包内置）
2. 用户目录 `%APPDATA%\StarWish\sources`（导入）
3. 开发态 `app/sources`

同名文件以先加载者为准；用户导入的新文件会自动获得唯一文件名，不会覆盖内置脚本。
