## 🔧 修复与增强（v2.2.0）

### 播放页背景
- 设置 →「外观主题」新增**播放页背景**四选一：封面模糊 / 动态渐变 / 壁纸 / 纯色。
- 封面模糊模式**随当前歌曲封面自动切换**（修复此前遮罩层盖住封面导致只显示纯色的问题）。
- 壁纸模式支持选择本地图片（移动端可直接从相册选图，自动压缩后保存），可一键清除。

### 插件库
- **插件不再内置**：安装后插件库为空，所有插件一律从「插件市场」/「订阅源」/「本地导入」安装。
- 插件列表取消分组，平铺展示。
- 插件与音源均支持**更新替换**：原地覆盖旧文件，保留启用状态，不会覆盖成停用。

### 导入歌单
- 链接解析重写（参考落雪 lx-music 源码）：支持网易云 / QQ / 酷狗 / 酷我 / 咪咕 / B 站各平台分享链接与歌单 ID。
- 粘贴链接后**自动切换到对应音源**；若手动选错音源会即时提示应切到哪一个。
- 支持 **QQ 官方分享短链**（`c6.y.qq.com/base/fcgi-bin/u?__=…`）——短码是服务端映射，程序自动跟随跳转取歌单 ID。
- 修复咪咕歌单接口失效导致的空列表，改用可用端点。

### 视频 / MV
- 循环模式改为**下拉列表选择**：不循环 / 单集循环 / **列表循环**。
- 画面模式同样改为下拉列表选择。
- **音量记忆**：MV 播放器音量会保存，下次进入自动恢复。

### 视频源歌词
- 视频源（bilibili）播放时自动获取并展示视频字幕（时间轴对齐）。

### 发现页
- 歌单增加**缓存机制**，切标签/切音源不再有切换延迟。
- 修复 QQ 歌单分类接口参数错误导致「没有找到歌单」的问题。

### 其它
- 主界面底栏音量条与播放页背景同色，滑块改为常显并显示百分比。
- 桌面端与移动端（Android）同步适配以上全部改动。

### 移动端（Android）适配修复
- 修复「是否桌面端」判断：移动端也注入了 `window.sw`，此前会误调桌面专属功能（视频离线缓存、打开外部浏览器），现改用构建期标记判定。
- 版本号不再硬编码（此前移动端固定报 2.1.0，会误提示「有新版本」），改为构建期从 `package.json` 注入，与桌面端一致。
- QQ 官方分享短链在移动端可正常解析：改走原生 HTTP 插件手动跟随跳转，直接取 302 的 Location。
- 插件库同样不再内置，与桌面端一致从插件市场 / 订阅源 / 本地导入安装。

## 📦 安装包

- Android：release APK / debug APK
- Linux：AppImage / deb（amd64）
