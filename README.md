## 简介

星河音乐（StarWish Music）是一个面向 Windows 的桌面音乐播放器。它本身不提供任何音乐接口，所有在线内容都来自你导入的 **音源脚本**——音源可以随时启用、停用、移除或恢复，播放器只负责把它们组织成一套顺手的听歌体验。

v2.0 使用 **Electron + Vue 3 + TypeScript** 全新重写：音频解码运行在独立的隐藏进程里，界面切换、列表滚动都不会打断播放；封面与音视频流统一走本地协议代理，解决了长期困扰的防盗链与跨域问题；歌曲、歌单、收藏、历史全部落盘到 SQLite。
该库是星河音乐（StarWish Music）的主题库，不包含任何发布内容，仅作为星河音乐（StarWish Music）内部使用

## 说明

- 本项目不内置、不托管任何音频文件，所有在线内容由用户导入的音源提供。
- 音乐版权归各平台与版权方所有，本软件仅供个人学习与试听，请勿用于商业用途。
- 界面中不出现任何官方音乐软件名称或标识，所有数据统一标注为「在线音源 / 本地音源 / 音源插件」。
